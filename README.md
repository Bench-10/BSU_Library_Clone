## 📖 Introduction  

#### *RLibrary+* is a redesigned Batangas State University Library System that aims to provide a modern, user-friendly, and fully responsive platform for students, faculty, and staff. Addressing issues like outdated design, limited search filters, and the lack of digital borrowing, the system will feature an organized search interface, improved filtering options, mobile compatibility, and a built-in online borrowing and reservation module. With integrated analytics for tracking usage and trends, RLibrary+ will centralize academic services, streamline workflows, and enhance the overall library experience.

---

## 🔍 Observations  

📌 Current challenges faced by users:  
- ❌ Borrowing system is not integrated 
- 🧭 Limited search and filter options    
- ⏳ No access to history or usage data
- 📱 No mobile responsiveness 

These issues reduce overall engagement and make the system frustrating for daily use.  

---

## ❗ Problem Statement  

The current system:  
- 🗂️ Is outdated and visually cluttered  
- 🔍 Lacks search flexibility  
- 📚 No built-in digital borrowing
- 🧾 Doesn't support borrowing history tracking  
- 📉 Has no analytics or decision support  

Students and faculty rely on this system heavily but it's limitations affect academic efficiency.  

---

## 🎯 Project Objectives  

**🎯 Main Goal:**  
Redesign the system into a modern, user-friendly, and data-driven platform for improved library services.  

**📌 Specific Goals:**  
- 🎨 Ensure full mobile responsiveness for seamless use on any device
- 📚 Integrate built-in online borrowing
- 📊 Integrate analytics for usage tracking and insights  

---

## ✅ Functional Requirements  

### 1. 👨‍🎓 Student Functions  
- 🔐 Login using SR-CODE + password  
- 🔎 Search by title, author, subject  
- 🏷️ Filter by material type & campus  
- 📖 View book details (availability, location)  
- 📥 Borrow or reserve online  
- 📜 Check borrowing history  

### 2. 👩‍💼 Library Staff Functions  
- 🔑 Admin access  
- 📜 Add New Resources
- ✅ Approve/reject borrow/reserve requests  
- 📝 Update book status  
- 🗃️ View logs of user activity  
- 📊 Monitor analytics and reports
